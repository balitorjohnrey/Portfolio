# John Rey Balitor Portfolio

This repository includes a one-page web portfolio for John Rey Balitor, a BSIT student and aspiring full-stack developer.

## Portfolio Files

The portfolio website is inside the `portfolio` folder:

- `portfolio/index.html`
- `portfolio/styles.css`
- `portfolio/script.js`
- `portfolio/assets/developer-workspace-hero.png`

## How To Open

Open `portfolio/index.html` in a browser to view the portfolio locally.

## GitHub Pages

If you want the portfolio to show as the main GitHub Pages website, move the files from `portfolio/` into the repository root, or publish the repository root and open:

```text
https://your-username.github.io/your-repository-name/portfolio/
```

GitHub shows this `README.md` on the repository page, but the actual website is the HTML file.
